TASK #91: INTEGRASI ATTRIBUTION SNIPER KE INTEL PLATFORM

KONTEKS
Simulator ini sering diakses melalui link yang disebar oleh "Sniper" (Intel Platform) 
via WhatsApp. Link tersebut membawa query parameters: 
?src=sniper&pt={slug_perusahaan}&tag={kategori_masalah}

Intel Platform sekarang sudah menyediakan endpoint publik LIVE untuk menerima 
data atribusi ini agar tim sales tahu lead mana yang sudah mengisi simulator.

ENDPOINT LIVE:
POST https://sniper-insight-ai.replit.app/api/sniper-leads/track-attribution

FITUR 1: CAPTURE & PERSISTENCE
1. Saat halaman Simulator dimuat (onLoad), baca URL query parameters: `src`, `pt`, `tag`.
2. Jika `src=sniper` ditemukan, simpan objek { src, pt, tag, timestamp } ke 
   `localStorage` dengan key `sniper_attribution`. 
   (Ini agar data tidak hilang jika user me-refresh halaman).

FITUR 2: UI BANNER
1. Jika `sniper_attribution` ada di localStorage, tampilkan banner kecil di atas form:
   "🔍 Diagnosa Lanjutan dari Intel-Konstruksi untuk [pt]" (gunakan warna biru/navy).

FITUR 3: WEBHOOK POST KE INTEL PLATFORM
1. Saat user menyelesaikan simulasi (klik tombol "Lihat Hasil" atau submit form akhir), 
   ambil data `sniper_attribution` dari localStorage.
2. Lakukan POST request (fire-and-forget / non-blocking) ke endpoint:
   URL: https://sniper-insight-ai.replit.app/api/sniper-leads/track-attribution
   Body: { pt: 'slug_perusahaan', tag: 'SMAP', simulator_result: 'MERAH/KUNING/HIJAU' }
   *Gunakan fetch dengan try-catch agar tidak memblokir user melihat hasil jika API gagal.*
3. Setelah dikirim, biarkan data di localStorage (atau hapus, sesuai preferensi UX).

FITUR 4: PASSING KE SCALEV (UPSELL TRACKING)
1. Saat user mengklik tombol CTA produk di halaman hasil (misal: "Beli Paket Sertifikasi ISO"), 
   tambahkan parameter `?ref=sniper_[pt]` ke URL Scalev. 

ACCEPTANCE CRITERIA
- Buka Simulator dengan `?src=sniper&pt=pt-test&tag=SMAP` -> Banner muncul.
- Isi form sampai selesai -> Network tab menunjukkan POST request berhasil ke endpoint Intel.
- Klik tombol beli produk -> URL Scalev membawa parameter referral.
